
# Setup


Follow the instructions to setup the project. Currently these have only been tested on Linux so if you are running Windows you will want to use Git Bash for the best results

```
# Create venv
python3 -m venv python-games

# Enter venv
cd ./python-games

# Clone repo
git clone https://github.com/jarwolpel/mini-python-games.git

# Activate venv
source ./bin/activate

# Install dependencies
pip install -r requirementes.txt
```

### Games

| Game | Description |Non-standard dependencies |
|:------:|:-----------:| :-----------------------: |
| Fighting Simulator | Choose 2 fighters, watch them battle to the death in epic text-based action! |None|
|Black Jack| Play a one player text based BlackJack game | None|
